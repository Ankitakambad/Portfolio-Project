# Portfolio Project with Python and SQL-Server-Management-System
This Python script performs a comprehensive analysis of e-commerce sales data using SQL queries, Python data processing, and visualization tools. It connects to a Microsoft SQL Server database via the pyodbc library and retrieves various datasets from tables such as customers, orders, order_items, products, and payments.
